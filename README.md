# 📖 Learning Philosophy

I believe programming isn't about memorizing syntax.

It's about understanding how to think.

Every lesson follows this process:

```
Learn
    ↓
Practice
    ↓
Make Mistakes
    ↓
Debug
    ↓
Understand
    ↓
Improve
    ↓
Repeat
```

Instead of rushing through tutorials, my goal is to truly understand each concept before moving forward.
